# 学习本 · 灵感调研板 (Mood Research)
> **Deliverable 1.2 — Phase 1: 品牌感知采集**  
> **Date:** 2026-04-13  
> **Product context:** 「乾卦·倪海厦天纪人间道」— A5 / 24页 / 骑马钉 / 圆珠笔可书写 / 小红书渠道  
> **Positioning:** 可书写的文化消费品（不是教科书，不是学术出版物，不是佛学/玄学杂志）

---

## 这份文档怎么用

这是一份"铺开整张桌子"的调研板，目的是把**和学习本气质可能相关的参考**集中在一处，让 GUA 能用自己的眼睛筛一遍。内容分四大类（同类产品 / 跨文化 / 材质印刷 / 排版）+ 一段跨类别观察。每条参考都尽量给出可追溯的来源。

**建议的使用方法**：
1. **先快速扫一遍**（不做任何判断），感受整个谱系的宽度，从"极古典的线装书"到"极现代的无印良品"。
2. **再回头逐条标记**：在每条后面的 `GUA:` 位置写下「喜欢 / 不喜欢 / 有启发 / 中性」+ 一句话原因（可以非常主观，例如"太老气"、"太冷"、"这个封面材质感让我想到爷爷的旧书"）。
3. **最后看"跨类别观察"**，那是把所有参考共通的线索抽出来的一段文字，帮助你验证自己的偏好是否内在一致。
4. **这不是设计方案**——没有任何一条参考会原样用在学习本上。目标是把 GUA 的审美向量"定位"出来，供 Phase 2 做关键词提炼时用。

**一条重要的态度**：很多国内"国学 / 易经"视觉是反面教材（红配金、堆砌毛笔字、假印章、水墨背景+竹叶），我特意没把这类列为正面参考。本文第 1.3 节会说明这是个视觉陷阱。

## 1. 同类产品参考 (Comparable Products)

### 1.1 中国独立出版物 / 文化小册子

#### 1.1.1 读库 MOOK + "读库本"
- **名称 / Title**: 读库（MOOK）+ 读库本系列小册子
- **来源**: <https://www.duku.cn/> | 维基 <https://zh.wikipedia.org/zh-hans/%E8%AF%BB%E5%BA%93> | 澎湃《读库15年》 <https://www.thepaper.cn/newsDetail_forward_14284944>
- **简介**: 张立宪 2006 年创办的人文社科 MOOK，主刊采 125×185mm 开本、日本轻型纸、**全部灰皮封面**、**无腰封无推荐语**，只印书名期号。此外还有"读库本"小开本分册系列（"建筑史诗"、"医学大神"、MUJI《人与物》、哲学系等），每本薄、柔软、盈手可握。
- **为什么选它**: 它是中文世界里**"极简 × 文化阅读 × 订阅制"**这条路最成熟的样本，而且——**它正好证明了"不喧哗也能活下去"**。读库本系列的轻薄感、小开本、日本轻型纸、柔顺翻开，几乎每一条都和学习本的产品形态 1:1 重合。
- **可借鉴的具体元素**:
  - **单色封面 + 极少元素**（书名、期号，完）——反对封面堆料
  - **日本轻型纸装帧**（和学习本已定的蒙肯/轻型纸方向一致）
  - **系列感靠"同一套衣服不同号"**实现（灰皮 + 不同卦/不同册），而不是靠花哨的视觉差异
  - **字号小、字距疏、留白多**的内页节奏
- **风险/caveat**: 如果完全复制"灰皮 + 白字"，会像读库的盗版。学习本需要找到自己的"底色"（不一定是灰），但可以借鉴它"一色走天下"的克制。

#### 1.1.2 单向空间 ·《单读》
- **名称 / Title**: 《单读》（The One-Way Street）
- **来源**: <https://www.owspace.com/> | 豆瓣系列 <https://book.douban.com/series/4717> | 专访 <https://www.digitaling.com/articles/847118.html>
- **简介**: 许知远主编的全媒体文化出版品牌，每期一个主题（小说、诗歌、非虚构、文化评论）。由设计师设定了几个标准开本，坚持"平装、便携、简单 logo"的方针，不走豪华装帧路线。
- **为什么选它**: 《单读》证明了**"文化人出版物可以不需要'文化感'堆砌"**——他们的封面常常是一个几何色块 + 一两行字，封底大量留白。这种"当代文学感"的气质如果能嫁接到易经内容上，就会自然生出"现代读者读古书"的氛围，而不是"古书给现代读者看"的居高临下。
- **可借鉴的具体元素**:
  - **主题色每期不同，但视觉结构保持一致**——学习本做"乾/坤/巽/震……"系列时的延展思路
  - **中西混排的克制感**（中文标题 + 英文副标的组合）
  - **不怕留白**，文字常只占封面 1/3 面积
- **风险/caveat**: 单读的气质偏"文青思辨"，学习本内容是倪海厦的直白解读，**气质应该更"落地"、更"师长"、更"不装"**，不要被单读的"漂浮感"带跑。

#### 1.1.3 理想国 · 看理想 系列
- **名称 / Title**: 理想国 / 看理想
- **来源**: <https://www.ilixiangguo.com/> | 百度百科 <https://baike.baidu.com/item/%E7%9C%8B%E7%90%86%E6%83%B3/53876717>
- **简介**: 广西师大出版社旗下独立厂牌，近十几年中国最前沿的文化出版品牌之一。2015 年延伸出"看理想"影像 + APP 品牌，针对年轻读者习惯。其装帧以**定制护眼字典纸**、**180°平摊书脊**、**小开本口袋书**著称。
- **为什么选它**: 理想国给我们演示了**"把严肃内容做出当代消费品气质"**的路径——它的读者是都市白领和大学生，包装像独立杂志，但内容是尼采、柏拉图、社会学。这正是学习本想做的事：**易经不是庙里的，是书架上的**。
- **可借鉴的具体元素**:
  - **字典纸（或薄轻型纸）的翻页手感**
  - **小开本 / 口袋书定位**
  - **看理想 APP 的"类印刷体界面 + 艺术展馆式排版"审美**（见百度百科描述）
  - **"严肃内容 × 轻盈外壳"的反差美学**
- **风险/caveat**: 理想国偏"人文社科"、"欧美思想"，气质略冷；学习本需要更多一点东方温度，**但不能松懈成"文艺青年"那种松散**。

#### 1.1.4 《知中》MOOK 系列 (苏静 / 中信出版)
- **名称 / Title**: 《知中》（China Intellectual）— 苏静主编
- **来源**: 搜狐专访 <https://www.sohu.com/a/156459702_492095> | 中信出版
- **简介**: 由做《知日》成名的苏静团队延伸的"中国文化主题 MOOK"，已出《山水》《民谣啊民谣》《孙子兵法》《山海经》《竹林七贤》等多期，**每期一个垂直文化主题、专题深度调研、图文并重**。
- **为什么选它**: 《知中》是**"把中国文化做成年轻人愿意看的专题杂志"**的代表样本——而且它的文化调性明显受日本 MOOK（尤其是 BRUTUS、和楽）影响，避开了传统"国学"出版物的老气。学习本（卦 → 卦 → 卦）本质上也是一个系列化、主题化的文化出版模型，可以直接借鉴《知中》的"每期一主题"结构。
- **可借鉴的具体元素**:
  - **"一主题一册"的系列逻辑**
  - **封面常有一个大主题字 / 符号作为视觉主体**（可呼应卦象作为学习本的封面主角）
  - **图文并重的内页节奏**（不纯文字也不纯图）
- **风险/caveat**: 《知中》视觉偏"杂志感"、图片密度大，学习本 24 页小册子容量更小，**不能学它的"满"，只能学它的"有主角"**。

#### 1.1.5 朱赢椿 · "虫子"系列 / 随园书坊
- **名称 / Title**: 朱赢椿 — 《虫子书》《虫子旁》《蚁呓》《不裁》等
- **来源**: 理想国 <https://www.ilixiangguo.com/author/author/view/id/14> | 澎湃专访 <https://m.thepaper.cn/newsDetail_forward_9844606> | 百度百科 <https://baike.baidu.com/item/%E6%9C%B1%E8%B5%A2%E6%A4%BF/7401471>
- **简介**: 南京师大出版社设计总监，多次"中国最美的书"、"世界最美的书"获奖者。代表作《不裁》是**读者自己用裁纸刀切开书页**来阅读；《虫子书》用虫子在纸上爬出的痕迹作为"文字"。
- **为什么选它**: 朱赢椿代表了**"中国本土书籍设计的极简、自然、参与式"**这一脉——他从德国书籍设计展获得启发："回归阅读本身才是最美的书"。**"让读者参与完成这本书"**这个思路和学习本的"可书写"属性在哲学上是完全同构的。
- **可借鉴的具体元素**:
  - **"未完成感"的设计哲学**——笔记区不是装饰，是邀请读者"完成这本书"的一部分
  - **大量黑白灰、极淡色调，像水墨画的质感**
  - **安静——封面几乎不卖力气**
- **风险/caveat**: 朱赢椿的设计个人艺术性非常强（自然观察、虫子痕迹），学习本需要的是**"可复制的系统"**而不是"一次性艺术品"，借鉴气质而非形式。

### 1.2 日本文化类小册子 / 独立出版

#### 1.2.1 d design travel 系列 (D&DEPARTMENT)
- **名称 / Title**: d design travel（全 47 都道府县系列）
- **来源**: 官网 <https://www.ddepartment.com/en/2018000100156.html> | d47 MUSEUM <https://www.hikarie8.com/d47museum/>
- **简介**: 长冈贤明（D&DEPARTMENT 创始人）2009 年发起的文化地理杂志系列，**每个都道府县一册**，编辑团队亲自去住两个月做田野调查，192 页，B5 变形开本，日英双语全彩。背后的理念是"Long-Life Design"（长销设计）。
- **为什么选它**: d design travel 是**系列化地域文化 MOOK 的金标准**——如果学习本想做"乾、坤、屯、蒙……" 64 本的长期系列，这个项目的**版式恒定、主题变化、封面模数化**逻辑直接可借鉴。而且它的设计语言**朴素到近乎无聊，但正是这种"不表演"让它耐看**。
- **可借鉴的具体元素**:
  - **封面固定模数**（同一位置放主题名，同一位置放编号）
  - **大量无衬线字体 + 日文明朝体的混排**
  - **书名以"系列名 + 主题名"的结构呈现**（d design travel TOKYO → 学习本 · 乾）
  - **色调克制——基本是黑白灰 + 每期一个主题色**
- **风险/caveat**: d design 过于"设计杂志气"，学习本不是设计刊物；气质上要更"书房"、更"手感"而非"展览"。

#### 1.2.2 《暮しの手帖》(Kurashi no Techo)
- **名称 / Title**: 暮しの手帖 — 日本老牌生活文化杂志
- **来源**: 官网 <https://store.kurashi-no-techo.co.jp/> | 人民图形设计档案 <https://peoplesgdarchive.org/item/9465/kurashi-no-techo>
- **简介**: 1948 年创刊、至今 78 年，**不接任何广告、靠订阅生存**。前主编花森安治一个人做插画、排版、摄影、写稿。松浦弥太郎后来也曾担任主编。这是日本"生活美学文化刊物"的鼻祖。
- **为什么选它**: 暮しの手帖证明了**"内容诚实 + 设计朴素 = 可以活 75 年"**。它的插图多是**花森安治手绘的水彩/色铅笔**，标题字是**手写为主的仿宋系**，排版温暖、舒缓、不匆忙——这正是一本**想让你"坐下来读"**的小册子需要的气质。
- **可借鉴的具体元素**:
  - **手绘感的封面主图**（如果学习本某一版本想试"手绘乾字 / 手绘卦象"方向）
  - **温暖偏黄的纸色 + 低饱和度封面用色**
  - **"主编像个老朋友"的叙述口吻**——和倪海厦"直白、不装、像说话"的气质非常合
- **风险/caveat**: 暮しの手帖是"昭和的安静"，有怀旧底色；学习本是**给 2026 年小红书年轻人**看的，可以借鉴它的"节奏"但不要借鉴它的"岁数"。

#### 1.2.3 松浦弥太郎相关出版物 (COW BOOKS / きほんのき)
- **名称 / Title**: 松浦弥太郎的书籍 — 代表作《最糟也最棒的书店》、《きほんのき》、《松浦弥太郎的きほん》
- **来源**: 扶桑社 <https://www.fusosha.co.jp/books/detail/9784594097219> | 维基 <https://ja.wikipedia.org/wiki/%E6%9D%BE%E6%B5%A6%E5%BC%A5%E5%A4%AA%E9%83%8E>
- **简介**: 松浦弥太郎（前 COW BOOKS 店长、前《暮しの手帖》主编）自己出的一系列小书，主题是"生活的基本"、"仕事的基本"、"健康的基本"——用极少的字讲一件事，书本身装帧也极简。
- **为什么选它**: 这一系列**"小本 × 少字 × 留白 × 基本"**的气质，和学习本"4000 字正文 × 24 页 × 可书写"的体量是同构的。松浦的书告诉我们：**"薄不代表轻，留白是一种态度"**。
- **可借鉴的具体元素**:
  - **标题只用 1-3 个字**（例："基本"、"きほん"）— 学习本封面只用"乾"或"☰"也许就够了
  - **每页只放一件事**的节奏感
  - **封面常常只是一张照片 + 书名 + 作者**，不装饰
- **风险/caveat**: 松浦的美学偏"素食感"、"低盐低糖"，如果全照搬，学习本会显得有点"文艺咖的营养餐"；倪海厦的内容是**辣的、有脾气的、敢说的**，视觉要能承载这种能量。

#### 1.2.4 《銀花》杂志 (杉浦康平设计时期)
- **名称 / Title**: 《銀花》— 文化传统与亚洲民艺主题杂志（杉浦康平长期封面设计）
- **来源**: 百度百科 <https://baike.baidu.com/item/%E6%9D%89%E6%B5%A6%E5%BA%B7%E5%B9%B3/4068233> | 中国文艺网 <https://www.cflac.org.cn/ys/xwy/201309/t20130902_220223.htm>
- **简介**: 日本介绍传统文化、民艺、手工艺的老牌杂志。杉浦康平从 1970 年代起长期担任封面设计，被视为**"东方图像学 × 现代网格系统"**的范本。他同时设计过《传真言院两界曼荼罗》等佛教艺术书，1979 年获日本总理大臣奖。
- **为什么选它**: 杉浦是**最懂"用现代设计语言承载东方哲学"**的人——他说"设计的本源就是汉字"，他把曼荼罗、阴阳、星象都做成了**严谨的网格化视觉系统**。乾卦的阴阳爻结构其实就是一个**天然网格**，杉浦的工作方法直接证明了这条路行得通。
- **可借鉴的具体元素**:
  - **严谨的网格系统 + 大胆的对称/几何构图**
  - **东方主题用现代平面语言表达**（不靠水墨堆积）
  - **图形化的文字**——汉字本身就是图像
- **风险/caveat**: 杉浦作品本身非常"作者化"、密度高、信息繁复，学习本是 24 页小册子而非百科巨册，**学其方法论，不学其密度**。

#### 1.2.5 Hobonichi Techo + 1101 出版物
- **名称 / Title**: 糸井重里主持的 ほぼ日 / Hobonichi 出版体系（手帐 + 相关小书）
- **来源**: 官网 <https://www.1101.com/store/techo/en/> | Wikipedia <https://en.wikipedia.org/wiki/Hobonichi_Techo>
- **简介**: 糸井重里的 Hobonichi 手帐从 2001 年卖到 2026 年每年 80 万本以上。自 2025 年起用新 Tomoe River Paper S，3.7mm 方格，每页都可以平摊。哲学是"只给你恰好够的引导，不把你框死在任何格式里"。
- **为什么选它**: **Hobonichi 是"可书写的文化消费品"这个品类的世界级标杆**——它证明了一件事：**一个空白/半空白的本子，只要纸张 + 装订 + 每日一句引言处理得好，就能卖 25 年**。学习本和它的定位最接近：不是纯内容书，也不是纯笔记本，是**两者中间的那个空间**。
- **可借鉴的具体元素**:
  - **平摊装订**（骑马钉对 24 页来说天然平摊，这已经具备了）
  - **每页边缘的低调引言**（学习本可在页脚/页眉放一句倪海厦的小结或易经原文短句）
  - **极淡的方格/点阵底纹**（帮助写字但不抢戏）
  - **封面保留极多留白供用户自己贴标签/写字**
- **风险/caveat**: Hobonichi 是"日用工具"，学习本是"阅读 + 书写"的混合体；不要完全滑向"日历 / 手帐感"，**学习本必须先读得下去，再写得起来**。

### 1.3 易经/国学类新媒体内容的视觉风格 (小红书/抖音)

> **注意**：这一节我专门诚实标注。国内"国学 / 易经"赛道**绝大多数视觉风格是反面教材**，不是正面参考。这里列出的是趋势观察，而不是"学习本应该长这样"。GUA 需要知道**同行业的视觉噪音是什么**，才能知道自己要避开什么。

#### 1.3.1 主流国学/玄学账号的典型视觉套路（通用印象，未具体核实单一账号）
- **名称 / Title**: 大多数小红书/抖音国学玄学账号的视觉共性
- **来源**: 行业观察文章《在小红书上万物皆可玄学》<https://view.inews.qq.com/a/20240327A03SOP00> | 蜗牛知享《小红书国学项目实操》<https://www.woniuboke.cn/20574.html> | 抖音搜索"国学玄学博主"
- **简介**: 头像用山水/观/庙/太极图，封面图喜欢用**红金配色、毛笔字体、水墨云纹、烫金印章、竹子/扇子/茶具**等元素堆砌。文案常走"天机不可泄露"、"懂的人自然懂"的神秘路线。
- **为什么列在这里（作为反面案例）**:
  1. 这是**"国学视觉噪音"的标本**——学习本的视觉第一反应必须是"这不是那一挂的"
  2. 倪海厦的内容风格恰恰是**反玄学、反故弄玄虚**的。视觉如果还是这套，就和内容气质打架
  3. 年轻用户在小红书滑过这些视觉已经视觉疲劳了，**"不长这样"本身就是差异化**
- **可借鉴的具体元素（反向）**: 以下都要**避开**：
  - 红 + 金为主色
  - 仿古毛笔字作为正文字体
  - 印章作为装饰
  - 水墨山水或竹子做背景
  - "天机 / 神机 / 真谛"类神秘化词汇
- **风险/caveat**: 也要警惕矫枉过正——完全"去东方"变成"极简性冷淡"会失去学习本自己的文化温度。

#### 1.3.2 "小红书诗歌"现象 (隔花人、焦野绿、祺白石 等年轻诗人)
- **名称 / Title**: 小红书"诗人现象"的视觉审美
- **来源**: 数英《对话4位在小红书写诗的年轻人》<https://www.digitaling.com/articles/922725.html> | 澎湃/北京日报《每周 2500 万人在小红书读诗》<https://xinwen.bjd.com.cn/content/s63c53dfce4b043bcce2be559.html>
- **简介**: 2022 年前后小红书上冒出一批写诗的年轻博主（隔花人、焦野绿、祺白石、小韬 CHENTY 等），粉丝数十万，排版**不用古诗词的毛笔字滤镜，而是用纯文字 + 少量留白 + 手写本照片 + 低饱和底色**。他们的内容是诗，但视觉不是"诗意朦胧"而是"日常安静"。
- **为什么选它**: 这个现象证明了——**年轻人并不排斥"文字为主的内容"**，他们排斥的是"被包装成装饰品的文字"。这批账号的视觉审美是学习本**在小红书上最接近的同温层**。
- **可借鉴的具体元素**:
  - **"手写 + 纸张"的真实感**（拍摄一张纸上的字，比任何 ps 滤镜都动人）
  - **低饱和大地色**（米、黄、棕、灰）
  - **一张图就一句话**的节奏
  - **不用花字体，用好的黑体/宋体**
- **风险/caveat**: 小红书诗人偏"个人抒情"，学习本是**"千年文本 + 老师解读"**，气质上要比这些账号更"有分量"、更"像师长"、而不是"像同龄人"。

#### 1.3.3 "看理想" APP / 单向空间 小红书号
- **名称 / Title**: 看理想 + 单向空间 的小红书官方号
- **来源**: 看理想 <https://baike.baidu.com/item/%E7%9C%8B%E7%90%86%E6%83%B3/53876717> | 单向空间 <https://www.owspace.com/>
- **简介**: 这两个账号是**文化品牌在小红书上最克制的范本**。基本套路：一张单色背景图 + 一句话 + 一小段作者介绍。几乎不上色彩，不上滤镜，不上花字。
- **为什么选它**: 它们告诉小红书的算法："文化内容可以不用热闹也能有流量"。学习本要进小红书，**靠的是内容稀缺性 + 视觉识别度**，不是"热闹"。
- **可借鉴的具体元素**:
  - **图文比 1:1 到 1:2**（不要一屏到底都是文字）
  - **主色不超过 3 种**
  - **常常是"一张图 = 一张名片"**（纯文字卡片式封面）
- **风险/caveat**: 这两家的气质偏"城市知识分子"，学习本内容更"民间师长"一点——可以克制但不能"凉"。

#### 1.3.4 "一条 / 物道 / 有束光" 等生活美学号（通用印象，未具体核实）
- **名称 / Title**: 文化生活号的视觉审美（一条、物道、有束光、文化有腔调 等）
- **来源**: 通用行业印象 / 未具体核实某一篇
- **简介**: 这批账号在小红书/公众号上做"东方美学 × 器物 × 生活"的内容，视觉上**以灰调、米色、大量留白、少量器物高清特写**为主，正文字体偏思源宋体/中等字重。
- **为什么选它**: 这是**"东方气质 × 当代消费"**审美在中文互联网上最成熟的一脉，学习本在小红书上会和它们出现在同一个推荐流里，**视觉识别系统至少要能在这个流里"站得住"**。
- **可借鉴的具体元素**:
  - **高级灰 + 暖米色 + 一抹克制的主题色**
  - **器物/纸张的特写作为主图**（可以给学习本拍"一本翻开的样子"作为主视觉）
  - **中英文混排的排版节奏**
- **风险/caveat**: 这类号的气质容易滑向"精致生活方式博主"的甜味——学习本不是"生活方式"，是**"工具 + 文本"**，要保留一点"不好惹"的硬度。

## 2. 跨文化参考 (Cross-Cultural References)

### 2.1 日本现代设计 × 传统文化

#### 2.1.1 MUJI 书籍 / 原研哉 (Kenya Hara)
- **名称 / Title**: 原研哉设计的 MUJI 出版物（《Designing Design》《White》《100 Whites》等）+ MUJI BOOKS 系列
- **来源**: Lars Müller Publishers <https://www.lars-mueller-publishers.com/kenya-hara> | Wikipedia <https://en.wikipedia.org/wiki/Kenya_Hara> | MUJI USA <https://www.muji.us/products/designing-design>
- **简介**: 原研哉自 2001 年任 MUJI 艺术总监，核心理念是"emptiness"（空/留白）。他的书《白》《100 Whites》本身就是一本以"白"为主题的当代设计学论述，把日本禅宗的"间"概念翻译成可操作的版面系统。
- **为什么选它**: 原研哉是**"东方哲学 × 现代设计语言"**这条道路上最清晰的样板——他没有用毛笔字、水墨、竹子任何一个符号，却让全世界都认为他的设计"非常日本"。**这正是学习本要走的方向：不靠符号堆砌，靠系统和留白传达东方气质。**
- **可借鉴的具体元素**:
  - **"空"作为主动的设计语言**，而不是"还没填的地方"
  - **白/米色作为主色系**，几乎不使用饱和色
  - **字号克制，字距大，行高大**
  - **把一个符号（比如 ☰）放在足够大的留白里，让符号本身成为封面**
- **风险/caveat**: MUJI 气质偏"无性格"、"无作者"，学习本的作者（倪海厦）是**极有性格的人**——不能完全冷掉，需要保留"有老师在说话"的温度。

#### 2.1.2 中川政七商店
- **名称 / Title**: 中川政七商店（奈良，1716 年创业的工艺品牌）
- **来源**: 官网 <https://www.nakagawa-masashichi.jp/company/> | good design company <https://www.gooddesigncompany.com/brands/nakagawamasashichi>
- **简介**: 300 多年历史的奈良麻织品老店，2007 年起由 good design company 重做品牌，slogan 是"让日本工艺重新有活力"（日本の工芸を元気にする）。品牌语言是**大量白 + 日文"中川政七"四个宋体字 + 极简器物摄影**。
- **为什么选它**: 中川政七证明了**"传统工艺 → 当代消费品"**这个翻译可以做得多漂亮——他们没有把"300 年老店"做成"仿古气"，而是做成了一个**"让老手艺进现代人客厅"**的体面品牌。这和学习本想把易经"从故纸堆带到年轻人书架"是同一个转译任务。
- **可借鉴的具体元素**:
  - **品牌名用宋体，字重克制**（学习本标志也应如此）
  - **主色非常少，但"品牌色"识别度强**（中川政七用一个很特别的暖灰蓝）
  - **"工艺"作为卖点，但讲故事时用现代人的语言**
  - **产品摄影极干净，几乎不加道具**
- **风险/caveat**: 中川政七的体量大、SKU 多，有完整的"店铺体验"；学习本是单品 + 系列的小册子，**学其语言而非其规模**。

#### 2.1.3 深泽直人 相关出版物
- **名称 / Title**: 深泽直人（Naoto Fukasawa）的书与产品设计
- **来源**: 豆瓣 <https://book.douban.com/subject/26865865/> | 百度百科 <https://baike.baidu.com/item/%E6%B7%B1%E6%B3%BD%E7%9B%B4%E4%BA%BA/20161681>
- **简介**: ±0 品牌创始人、MUJI 核心设计师之一。代表理念"Without Thought"（无意识设计）— 好设计就是让用户感觉不到设计的存在。他的个人作品集《深泽直人》装帧朴素，正文黑白为主。
- **为什么选它**: "无意识设计"的哲学特别适合**笔记本/小册子类产品**——一本让人拿起就想写、翻开就想读的小册子，它的设计不应该"在说话"，它应该让内容和笔自己说话。这正是学习本"可书写的文化消费品"应有的设计态度。
- **可借鉴的具体元素**:
  - **产品形式服务使用场景**（A5 单手持、骑马钉平摊、笔记区位置适合惯用手 — 这些都是"无意识"）
  - **材质本身就是装饰**，不额外加工艺
- **风险/caveat**: 深泽直人美学偏"匿名"、"去作者"，学习本还是需要一个"品牌人格"——所以**学其克制，不学其匿名**。

#### 2.1.4 侘寂 (Wabi-Sabi) 美学在印刷品上的应用
- **名称 / Title**: 侘寂（わびさび）美学作为设计方法论
- **来源**: Wikipedia <https://en.wikipedia.org/wiki/Wabi-sabi> | Dezeen 标签 <https://www.dezeen.com/tag/wabi-sabi/>
- **简介**: "侘"指简素朴拙之美，"寂"指时间沉淀的痕迹感。核心特质：不对称、粗糙、节制、克制、亲密、自然磨损。
- **为什么选它**: 侘寂给学习本提供了一个**"允许不完美"**的美学授权。蒙肯纸本身略带米黄、不是纯白，有纸浆的自然瑕疵——这在侘寂语境下**不是缺点而是优点**。学习本在小红书上露出时，不需要追求"完美商品感"，反而可以拍出"翻过的、写过的、有折痕的"样子。
- **可借鉴的具体元素**:
  - **接受纸张自身的米黄和肌理作为封面色**（而不是追求纯白光面）
  - **不对称构图**（封面标题不居中也可以）
  - **"用过的"场景摄影**作为小红书主视觉
- **风险/caveat**: 侘寂容易被误读为"破旧 / 脏脏风"——真侘寂是**"高成本做出朴素感"**。学习本仍需是印刷精致的成品，只是**视觉语言允许朴素**。

#### 2.1.5 D47 MUSEUM / 长冈贤明 (Kenmei Nagaoka)
- **名称 / Title**: D47 MUSEUM + Long-Life Design 理念
- **来源**: d47 MUSEUM <https://www.hikarie8.com/d47museum/> | D&DEPARTMENT <https://www.ddepartment.com/en_US/museum.html>
- **简介**: 长冈贤明主持的日本首座"设计博物馆"，在涩谷 Hikarie 八楼，主题是"47 都道府县的长寿设计"。品牌理念是"Long-Life Design"——好设计是能活得久的设计。
- **为什么选它**: 这个理念**直接回答了学习本的一个关键问题**："一本小册子，值不值得被留在书架上 5 年、10 年？" 长冈的答案是——**设计不追求惊艳、追求耐看**。学习本的视觉就应该这样：第一眼可能不惊艳，但第十次翻开还觉得舒服。
- **可借鉴的具体元素**:
  - **克制到"普通"的封面**（过几年不显过时的标志）
  - **纸张和装订的品质决定耐看度**（而不是封面印花）
  - **系列感由"长得像"决定，不是"长得花"**
- **风险/caveat**: D47 的定位是"博物馆/文化机构"，偏冷；学习本是**可书写消费品**，气质要多一点"想拿起来翻"的邀请感。

### 2.2 韩国 / 台湾 传统文化现代化

#### 2.2.1 小器 (Xiaoqi, 台北)
- **名称 / Title**: 小器生活 / 小器藝廊 / 小器食堂
- **来源**: 官网 <https://www.thexiaoqi.com/> | 关于 <https://www.thexiaoqi.com/pages/about-xiaoqi>
- **简介**: 2012 年在台北赤峰街开的选物店，核心是"介绍日本成熟的工艺/民艺等生活器皿"，也开发台湾本土原创的 +t 系列（台湾水果玻璃杯、十三生肖玻璃杯等）。品牌语言极度克制、浅色调。
- **为什么选它**: 小器是**"华语圈做日系美学最成熟的样本之一"**。它在台北（而不是东京）证明了日式克制审美可以在华语生活场景里落地。对学习本来说，小器的**"原产地 ≠ 原始语境"**这件事很有启发：学习本的内容是中国古典，但视觉语言可以自由吸收日本经验。
- **可借鉴的具体元素**:
  - **米白 + 浅木色 + 一抹主题色**
  - **产品摄影以侧光 / 自然光为主**
  - **品牌名字体用宋体或仿宋**
- **风险/caveat**: 小器是实物器皿品牌、学习本是纸质出版物——借鉴气质而非品类逻辑。

#### 2.2.2 诚品书店 (Eslite)
- **名称 / Title**: 诚品书店
- **来源**: 维基 <https://zh.wikipedia.org/zh-cn/%E8%AA%A0%E5%93%81%E6%9B%B8%E5%BA%97>
- **简介**: 台湾最有影响力的连锁书店，定位"人文、艺术、创意、生活"，带动了台湾图书分类方式的改革（按主题/情绪分类，而非按学科）。
- **为什么选它**: 诚品的**"把书当体验 + 生活方式"**的做法，直接影响了大陆的方所、单向空间、先锋书店。学习本如果进诚品类书店的陈列，**气质应该能和诚品选物区自然融合**——这就是学习本的"陈列感"审美基准。
- **可借鉴的具体元素**:
  - **书的摆放场景** — 学习本在小红书图片里应该能想象被放在诚品式书店里不违和
  - **"主题而非学科"的分类方式**启发学习本的系列逻辑（"乾"是一个主题，不是一个学科章节）
- **风险/caveat**: 诚品是"空间品牌"，不是单品设计；学习本借鉴它的"文化气质基准线"即可。

#### 2.2.3 王志弘 (Wang Zhi-Hong, 台湾书籍设计师)
- **名称 / Title**: 王志弘设计的书籍封面系列
- **来源**: 优设 <https://www.uisdc.com/wangzhihong>
- **简介**: 台湾新生代书籍设计师代表，将台湾、中国、日本、西方文化元素融合，风格"古典与现代相结合"。第一批使用电脑做设计的华语设计师，**专注中文字体结构和视觉节奏**。早期作品做过很多中文字排列研究，内页字距行间天地留白拿捏极好。
- **为什么选它**: 王志弘是**"华语世界最懂中文字体节奏的设计师"**之一，他的封面经常只有几个中文字 + 一点几何，却能站得住。学习本封面如果走"纯中文 + 卦象符号"路线，王志弘的工作方法是最直接的参考。
- **可借鉴的具体元素**:
  - **中文字体的"字重 × 字距 × 位置"作为封面唯一元素**
  - **内页字距行间的克制**
  - **中西混排时用一点点小写英文作为辅助线**
- **风险/caveat**: 王志弘风格太"王志弘"，学习本不能照搬，只能学方法论。

#### 2.2.4 聂永真 (Aaron Nieh, 台湾)
- **名称 / Title**: 聂永真 — 唱片 + 书籍装帧设计
- **来源**: 维基 <https://zh.wikipedia.org/zh-hans/%E8%81%B6%E6%B0%B8%E7%9C%9F> | 理想国专访 <https://www.chinanews.com.cn/cul/2011/08-26/3287638.shtml>
- **简介**: 台湾新世代设计代表，林宥嘉专辑《感官/世界》《小凑恋歌》设计获两届金曲奖。气质偏**"当代、年轻、克制中带一点叛逆"**。
- **为什么选它**: 聂永真给学习本提供另一种可能性——**"文化内容是否一定要走老派路线？"**。他证明了即使是古典主题，封面也可以是一个**近乎极简主义 MV 风格**的海报。学习本可以考虑在某一个视觉方向里大胆走"当代海报风 + 乾字"。
- **可借鉴的具体元素**:
  - **单一主图 + 大字 + 一个亮色**的海报式封面
  - **中英双语混排的青年气质**
  - **留白比传统书封面更激进**
- **风险/caveat**: 聂永真太"潮"，学习本内容需要一定的**"岁数感"（不是老气，是沉淀感）**，完全用聂永真风格会显得"国学被做成了嘻哈专辑"。

#### 2.2.5 《汉声》杂志 (Echo of Things Chinese)
- **名称 / Title**: 汉声 / Echo of Things Chinese（黄永松创办）
- **来源**: 维基 <https://zh.wikipedia.org/zh-hans/%E6%BC%A2%E8%81%B2%E9%9B%9C%E8%AA%8C%E7%A4%BE> | VERSE <https://www.verse.com.tw/article/cultural-history-echo-lionart>
- **简介**: 1971 年在台湾创立（英文版），1978 年中文版创刊。50 年来系统记录中华民间文化、建立"中华传统民间文化基因库"。2006 年获《Time Asia》"最佳行家出版物"。
- **为什么选它**: 汉声是**"华语世界做传统文化出版最深的一家"**。虽然它的视觉偏民俗感、略"旧"（部分封面接近田野档案气质），但它的**选题方法论和内容严谨度**是学习本要对标的——"做到最深而不是最热闹"。
- **可借鉴的具体元素**:
  - **"田野调查式的内容深度"** 作为内容态度
  - **基因库式的系列规划**（如果以后学习本扩展到 64 卦 + 诗经 + 道德经，汉声的"5 种 10 类 56 项"方法论可参考）

- **名称 / Title**: 朱赢椿《不裁》(获 2007 "世界最美的书")

- **简介**: 《不裁》给读者一把裁纸刀，让读者自己切开书页。纸张选择质朴、有韧性（可裁切不毛边）。

- **可借鉴的具体元素**:
  - **纸面粗糙度 × 圆珠笔阻尼感**的打样测试
  - **纸张厚度让翻页有"哒"的微微阻力感**
- **风险/caveat**: 朱赢椿是艺术品级别，学习本是零售消费品，**纸要好但不能贵到离谱**。

### 3.2 特种纸封面在文创小册子中的应用

#### 3.2.1 牛皮纸封面（通用方向 + 案例）
- **名称 / Title**: 牛皮纸做封面 — 典型案例《梅兰芳戏曲史料图画集》、社科文献甲骨文丛书《时情化忆》

- **简介**: 牛皮纸封面在中国文化出版中应用极广。代表案例：梅兰芳戏曲史料使用**"略带沧桑感的暖灰色牛皮纸 + 不加修饰的手写书名"**，表现"历史影响的特定年代语境"。
- **为什么选它**: 牛皮纸是**"低成本 × 高文化感"**的最佳组合。它本身就带米黄 + 木纹肌理，不需要额外印背景色；配合烫黑字或简单丝印就非常耐看。
- **可借鉴的具体元素**:
  - **封面直接用牛皮纸色做底色**（不印底色）
  - **单色印刷标题**（黑 / 深棕 / 墨）
  - **手写或手雕感标题字**
- **风险/caveat**: 牛皮纸已经被用得非常多，可能显"旧套路"。学习本用时需要**给它配一个非复古的元素**（比如一个现代几何的卦象）来打破"古董气"。

#### 3.2.2 特种纸 + 压凹 / 烫印封面（案例：甲骨文丛书）
- **名称 / Title**: 社科文献甲骨文丛书的特种纸封面设计
- **来源**: 澎湃《封面装帧》<https://m.thepaper.cn/yidian_promDetail.jsp?contid=6857748&from=yidian>
- **简介**: 甲骨文丛书的《罗马帝国的崛起》用**红色特种纸镂空 + 烫黑漆片**；《斯大林的战争》用**裸脊装**。代表了国内学术出版中"特种纸 + 工艺"组合的成熟案例。
- **为什么选它**: 给学习本在**封面工艺上留一条"升级路径"**——基础版可以是牛皮纸印黑字，高配版可以考虑**压凹的卦象（☰凸起触感）**或**烫印（金/银/黑/墨）**。
- **可借鉴的具体元素**:
  - **压凹做"☰"**（不印油墨，靠纸张凹痕形成阴阳爻）— 这个思路特别对易经语境
  - **书脊/封底用裸脊或者露线装订**的小工艺感
- **风险/caveat**: 工艺加太多会贵、会"炫技"、会让人感觉"摆在博物馆里而不是拿来写"。学习本是**工具**，所有工艺都要问"这帮到阅读 / 书写了吗？"

#### 3.2.3 宣纸感纸 / 拷贝纸 (Tracing Paper) 作为夹页
- **名称 / Title**: 宣纸感薄纸 / 拷贝纸作为书籍夹页的常见用法
- **来源**: 通用设计实践（没有单一案例，见各种文创书籍设计中间夹页）
- **简介**: 很多文化类书籍在章节分隔处夹一页**半透明的宣纸感薄纸**（印图案或全白），翻开时有**"隔层雾"的仪式感**。
- **为什么选它**: 学习本 24 页小册子容量有限，不一定用得起"夹页"，但**半透明纸的视觉语言**可以作为一个储备——如果以后扩展到 48 页或套书版本，夹页能做出"章节仪式"。
- **可借鉴的具体元素**:
  - **夹页印卦象轮廓**，翻开后和下一页的标题叠印
  - **光透出字**的动态阅读感
- **风险/caveat**: 24 页骑马钉不太适合夹页，**暂时只列作"未来备选"**。

#### 3.2.4 带纹路特种纸（纤维纸 / 草纸 / 素描纸）
- **名称 / Title**: 带自然纤维或纹路的特种纸（如"刚古""凝采""星采""蒙肯 Smartprint"等）
- **来源**: 知乎纸张攻略 <https://zhuanlan.zhihu.com/p/132636709> | 设计师纸张知识 <https://zhuanlan.zhihu.com/p/52982015>
- **简介**: 国内常用的文化品封面纸种类众多：刚古、凝采、星采、富丽等都属于"有纹路的特种纸"，价格中等，文化气质强。

## 4. 排版参考 (Typography & Layout References)

### 4.1 中文竖排 vs 横排 在小册子中的现代运用

#### 4.1.1 The Type 的《孔雀计划》
- **名称 / Title**: 孔雀计划：中文字体排印的思路（Eric Liu 主持，Type is Beautiful / The Type）
- **来源**: <https://www.thetype.com/kongque/> | 序言 <https://www.thetype.com/2019/02/12498/>
- **简介**: 2017 年 Eric Liu 发起的中文排版知识体系重建项目，从中文视角（而非翻译西文）讨论字号、行距、标点压缩、中西混排等原则。
- **为什么选它**: 这是**学习本做正文排版决策时最权威的中文参考**。它告诉我们："中文竖排不是装饰，而是一种阅读节奏；但在现代媒介中，横排不等于失去中文气质。"
- **可借鉴的具体元素**:
  - **标点压缩（避免"。"后面还保留一个字宽空格）**
  - **中西文之间 1/4 字宽间距**
  - **行距 × 字号比例：正文常用 1.6-1.75**
- **风险/caveat**: 孔雀计划是规则集，不是审美方案——学习本需要**在规则基础上做审美选择**。

#### 4.1.2 读库 MOOK 的横排节奏
- **名称 / Title**: 读库 MOOK 内页横排
- **来源**: 官网 <https://www.duku.cn/>
- **简介**: 读库是典型的**中文横排 + 大留白 + 极少装饰**的现代出版物。125×185mm 开本，字号 10-11 pt，行距约 1.75。
- **为什么选它**: 证明了**中文横排也可以有"古书气质"**——关键不在方向，在留白和字距。学习本如果选横排（比较大概率），可以直接参考读库的节奏。
- **可借鉴的具体元素**:
  - **页边距较宽**（内边距可以比外边距小一点，留笔记空间）
  - **段落间距 > 行间距**，视觉呼吸感
  - **不用首行缩进 + 用段落间距**，更现代
- **风险/caveat**: 读库的横排已经被大量模仿，学习本需要找到**"学其节奏、不学其表皮"**的分寸。

#### 4.1.3 台湾汉声 / 台版繁体竖排书
- **名称 / Title**: 台湾汉声杂志 / 台版传统文化书籍竖排
- **来源**: 汉声 <https://zh.wikipedia.org/zh-hans/%E6%BC%A2%E8%81%B2%E9%9B%9C%E8%AA%8C%E7%A4%BE>
- **简介**: 台版传统文化书籍许多仍保留竖排 + 繁体字传统（尤其《汉声》《文化月刊》等）。
- **为什么选它**: 对学习本来说这是一个**可选的"极古典版本"**方向——如果以后做限定收藏版（非主发行版），可以考虑竖排繁体古雅版。
- **可借鉴的具体元素**:
  - **竖排用于原文/爻辞部分，横排用于现代解读部分**（古今对照的排版策略）
- **风险/caveat**: 小红书年轻用户对竖排 + 繁体阅读门槛较高——**主发行版不宜走竖排主打**。只作为"古文区块"局部使用。

#### 4.1.4 《蒋勋说XXX》系列横排排版
- **名称 / Title**: 蒋勋系列（《蒋勋说红楼梦》《蒋勋说唐诗》《蒋勋说宋词》《汉字书法之美》等）
- **来源**: <https://weread.qq.com/web/search/books?author=%E8%92%8B%E5%8B%8B>
- **简介**: 蒋勋系列内容是**"古典文本 + 当代老师讲解"**，和学习本内容结构几乎一模一样。排版多为横排简体，老师讲解文字占主体，古文原文用不同字体 / 背景区分。
- **为什么选它**: **内容结构上的最直接同类**。学习本可以参考蒋勋系列的"解读 + 原文"双层排版逻辑。
- **可借鉴的具体元素**:
  - **解读用宋体或黑体，原文用楷体或仿宋**（视觉区分两种文本）
  - **原文单独成块、可能加一个浅底色或一个左侧竖线装饰**
  - **脚注 / 旁注用小字号灰色，不抢戏**
- **风险/caveat**: 蒋勋系列装帧偏"大众畅销书"味——气质要提炼，不要照抄。

### 4.2 古文 / 文言内容的现代排版案例

#### 4.2.1 书格 (Shuge.org) 对古籍的数字复刻
- **名称 / Title**: 书格 — 数字古籍图书馆
- **来源**: <https://www.shuge.org/>
- **简介**: 一个开放的数字古籍图书馆，收录宋元善本、明清刻本的高清 PDF。对设计师来说，这是**研究古籍版式最直接的素材库**。
- **为什么选它**: 给学习本做决策时提供**"古籍版式的真实面貌"**参考。古籍不是想象中的"古风"，它有自己的结构：栏线、鱼尾、鱼眼、单行与双行小字注的混排逻辑。
- **可借鉴的具体元素**:
  - **"大字正文 + 双行小字注"**的古籍体例，可以用在学习本"爻辞 + 解读"上
  - **页面中央的"版心线"**，可以作为现代版的边栏装饰
  - **鱼尾（古籍页眉处的装饰）**极简化后可作为现代 logo 灵感
- **风险/caveat**: 直接复刻古籍版式会让学习本变得"太老"——只取结构灵感，不取装饰符号。

#### 4.2.2 中华书局 / 上海古籍出版社的当代古籍整理本
- **名称 / Title**: 中华书局 / 上海古籍现代古籍整理版（如"中华经典名著全本全注全译"系列）
- **来源**: 通用行业印象（具体单本需进一步核实）
- **简介**: 中华书局整理本是华语世界**古籍现代排版的工业标准**。排版逻辑：原文（大字）+ 注释（小字，多为双栏或下挂）+ 译文（中等字号）。
- **为什么选它**: 学习本的"爻辞 + 倪海厦讲解 + 笔记"三层结构，可以直接参考古籍整理本的"原文 + 注 + 译"三层。
- **可借鉴的具体元素**:
  - **三种字号、三种字体的对比层次**
  - **不同文本类型用不同缩进 / 背景区分**
- **风险/caveat**: 中华书局整理本偏学术严肃，学习本要比它**"轻 50%"**——气质要像"年轻老师的讲义"而非"学院派考据"。

#### 4.2.3 吕敬人书籍设计作品
- **名称 / Title**: 吕敬人 — 从装帧到"五感"设计
- **来源**: 设计在线 <https://www.dolcn.com/archives/14104> | 今日美术馆回顾 <http://www.todayartmuseum.com/cnexhdetails.aspx?type=reviewexh&id=722>
- **简介**: 中国大陆书籍设计的转型代表人物，从"装帧"（只管封面）推进到"书籍整体设计"。代表作《中国记忆——五千年文明瑰宝》等。理念"不摹古却饱浸东方品味，不拟洋又焕发时代精神"。
- **为什么选它**: 吕敬人直接回答了学习本最核心的问题：**如何用现代设计语言承载东方内容 + 不落入仿古俗套？** 他从杉浦康平那里继承的"植根本土 + 吸取西方方法"是一个可执行的方向。
- **可借鉴的具体元素**:
  - **"五感设计"方法论**（视、触、嗅、听、味）— 学习本的笔记体验可以归入"触感设计"
  - **内页层次不靠装饰靠结构**
- **风险/caveat**: 吕敬人作品偏"大型精装"，学习本是小开本；气质借鉴即可。

#### 4.2.4 朱赢椿《蚁呓》的极简古典版面
- **名称 / Title**: 朱赢椿《蚁呓》
- **来源**: <https://baike.baidu.com/item/%E6%9C%B1%E8%B5%A2%E6%A4%BF/7401471>
- **简介**: 被联合国教科文组织评为"2008 最美图书特别奖"。内容讲蚁的生活，排版极简 — 大量留白，每页可能只有一行字或一只蚂蚁。
- **为什么选它**: 提供了一个**"文本可以不占满一页"**的极端案例。学习本 4000 字 / 24 页 = 平均每页 170 字，本身就已经有很多留白空间——可以大胆往"每页不满"方向做。
- **可借鉴的具体元素**:
  - **"一爻一页"的节奏**（乾卦 6 爻 + 用九 = 7 个独立页面，加上卦辞、彖传、象传等，正好可以铺满 24 页，气口十足）
- **风险/caveat**: 朱赢椿太艺术化，学习本需要节奏更紧凑一点——**不是"诗集"，是"讲义"**。

### 4.3 中文字体在文化类产品中的选择

#### 4.3.1 源流明朝体 (GenRyuMin)
- **名称 / Title**: 源流明朝体 GenRyuMin (基于 Source Han Serif 的修改版)
- **来源**: GitHub <https://github.com/ButTaiwan/genryu-font> | 字体有线 <https://font.doany.cn/f/genryumin-tw>
- **简介**: 基于思源宋体修改，字面略压缩、笔画的起笔收笔有更明显粗细变化，**重现铅活字印刷的韵味**。SIL Open Font License，免费商用。有 7 个字重。
- **为什么选它**: **源流明朝体是"古典气质 × 现代可用性"最平衡的中文宋体之一**。它不像思源宋体那么"标准教科书"，也不像方正清刻本那么"复刻感重"。学习本内容包含古文原文时，它是**极强的候选正文字体**。
- **可借鉴的具体元素**:
  - **作为学习本正文主字体的候选**
  - **配合更细的西文衬线字体做中西混排**
- **风险/caveat**: 在小字号（如 8pt 以下）下可能字面偏瘦、可读性下降，需要打样确认。

#### 4.3.2 思源宋体 (Source Han Serif)
- **名称 / Title**: 思源宋体（Adobe + Google 联合开源，SIL Open Font License）
- **来源**: Adobe Typekit <https://source.typekit.com/source-han-serif/cn/> | 设计达人 <https://www.shejidaren.com/si-yuan-song-ti.html>
- **简介**: 开源泛 CJK 字体，覆盖简繁日韩，7 个字重，**最标准的当代中文宋体**。
- **为什么选它**: 如果学习本追求"稳、中、不出错"，思源宋体是**最安全的选择**。它"足够宋体"但没有"戏份"。
- **可借鉴的具体元素**:
  - **正文用 Regular 或 Light 字重**
  - **标题用 Bold 或 Heavy**
  - **封面可以用 Heavy 字重做大字主标题**
- **风险/caveat**: 思源宋体太"普及"，缺少识别度——学习本如果想有视觉记忆点，可能需要**封面字用一个更有个性的字体（如源流明朝体、方正清刻本、或定制字）**，正文才用思源宋体。

#### 4.3.3 霞鹜文楷 (LXGW WenKai)
- **名称 / Title**: 霞鹜文楷 LXGW WenKai
- **来源**: GitHub <https://github.com/lxgw/LxgwWenKai> | 知乎介绍 <https://zhuanlan.zhihu.com/p/606535453>
- **简介**: 基于日本 FONTWORKS Klee One 衍生的开源中文楷体，兼有仿宋和楷体特点。2 万余字覆盖，SIL OFL 1.1 免费商用。近几年在独立出版、个人项目中极受欢迎。
- **为什么选它**: **文楷有一种"老师写黑板"的温度**——不像印刷楷体那么硬，不像手写楷体那么乱。学习本如果想让"古文原文"部分**有一点"手感 / 师长感"**，文楷是完美候选。
- **可借鉴的具体元素**:
  - **爻辞 / 原文用文楷**
  - **解读正文用源流明朝体 / 思源宋体**
  - **楷 + 宋的对比 = "老师讲 + 经典引用"的视觉分层**
- **风险/caveat**: 文楷字面大、偏可爱，大面积用可能显"手帐风"。**只作为原文强调字体，不做主力正文**。

#### 4.3.4 方正清刻本悦宋 / 方正苏新诗柳楷（需授权）
- **名称 / Title**: 方正清刻本悦宋 / 方正苏新诗柳楷
- **来源**: 方正字库 <https://www.foundertype.com/>
- **简介**: 方正出品的高质量中文字体，**清刻本悦宋**是高度复刻清代刻本宋体感的宋体，笔画起收有强烈的"凿刻感"；**柳楷**是从柳公权书法风格提炼的楷体。
- **为什么选它**: 这两款是**"国潮文化产品"最高频使用的付费字体**。学习本如果有预算购买商用授权（LOGO 单独授权约几千元），**封面用清刻本悦宋 + 爻辞用柳楷**会是非常强力的组合——但用得好与不好差距也大。
- **可借鉴的具体元素**:
  - **封面主标题用清刻本悦宋**（仅 LOGO 级别用，不用于正文）
  - **视觉记忆点极强**
- **风险/caveat**: **容易被做成"假古风"** — 清刻本悦宋 + 红配金 = 灾难。如果用这款字体，其他元素必须特别克制。需 GUA 判断预算与风险。

#### 4.3.5 黑体在文化产品中的应用 (思源黑体 / 汉仪旗黑)
- **名称 / Title**: 思源黑体 Source Han Sans / 汉仪旗黑 HYQiHei
- **来源**: 汉仪 <https://hanyi.com.cn/> | Adobe 思源
- **简介**: **思源黑体**是开源免费的现代黑体，覆盖广；**汉仪旗黑**是齐立老师（雅黑设计者）设计的商业黑体，有 25-105 多个字重。
- **为什么选它**: 学习本的**副标题、页码、导航信息**可以用黑体提供"现代感锚点"。纯宋体会让整本书显得过于古典；加一点无衬线黑体能瞬间"当代化"。
- **可借鉴的具体元素**:
  - **页码 / 页眉用思源黑体 Light**
  - **副标题 / 章节号用思源黑体 Medium**
  - **封面的英文 / 拼音辅助信息用黑体**
- **风险/caveat**: 黑体字重选错会破坏节奏——**一般用 Light 或 Regular，不用 Bold**。

## 5. Cross-cutting Observations (跨类别观察)

把以上 40 + 个参考放在一起看，能提炼出几条非常稳定的规律，以及几个必须避开的陷阱。

**共通策略 · 出现在几乎每一个"传统文化现代化成功案例"里的**：

1. **克制是核心语法**。从 MUJI 到读库到中川政七到松浦弥太郎到蒋勋系列——**把东西拿掉，而不是加上去**，是一切成功的起点。留白不是"还没填的地方"，是主动的设计决策（原研哉《白》的整本书都在论述这一点）。对学习本来说，"一页上只有一行字、一个 ☰ 符号、大片白纸"这样的极端选择是**值得认真考虑**的，而不是"太空了要填一点"。

2. **颜色极度少**。成功案例几乎都是**"一色或两色 + 极少量强调色"**。读库只有灰，MUJI 只有白+米色，中川政七一个暖灰蓝，单向街一本一个主题色但都低饱和。学习本完全可以做到**整本书只用 2 种主色**（如米白纸本 + 墨色印刷 + 一种"乾"的主题色做标记）。

3. **字体用 2-3 款，绝不超过**。源流明朝（或思源宋体）做正文 + 霞鹜文楷（或方正清刻本悦宋）做原文强调 + 思源黑体做导航信息。三款字体 × 合理字重 + 字号差异 = 足够应对学习本所有层次。

4. **材质本身就是装饰**。蒙肯纸的米黄、牛皮纸的肌理、MD 纸的微糙——**把纸当成设计元素的一部分**，就可以不印花纹、不加底色。

5. **系列感靠"同款不同号"而非"每期惊喜"**。d design travel、读库、知中、中川政七都是一个视觉结构跑到底，每期只换**主题色 + 主题字**。这是学习本做 64 卦或扩展系列的最佳蓝图。

6. **内容温度要能"说话"**。暮しの手帖、蒋勋系列、松浦弥太郎的书——设计最终不是表演给设计师看的，是让读者感到**"有一个人在跟我说话"**。倪海厦的讲解风格本来就自带"一个有脾气的老师在跟你说话"，**视觉不应该压住这个声音**。

**要避开的陷阱 · 国内国学赛道的典型翻车模式**：

- **土味国潮**：红 + 金 + 故宫元素堆叠。这是**最大的陷阱**——年轻用户在小红书上滑到这种立刻判断"不是我的菜"。学习本坚决不走这一路。
- **假古风**：毛笔字 + 水墨背景 + 印章 + 竹子 + 折扇 = 灾难套餐。每一样单独拿出来都可能有用，但**放在一起就是学院晚会的舞台背景**。
- **玄学化**："天机 / 神机 / 真言 / 奥秘"这类神秘化词汇 + 对应的八卦/太极/云纹等符号堆砌。**倪海厦内容本身就是反玄学的**，视觉一旦玄学化就会和内容打架。
- **宗教化**：佛教卍字 + 金色 + 莲花 + 宣纸。易经不是佛教——把易经做得像一本佛经的手抄本是常见的新手错误。
- **学术化**：学报体封面 + 大量小字 + 密集注释。学习本不是学位论文。

**针对"学习本 × 倪海厦"的特殊考量**：

- **倪海厦是直白的、敢说的、带一点反叛的**。他讲乾卦不会故作深沉，他会用大白话说"天行健就是这个意思——你别装死"。**视觉应该能匹配这种"老派中药柜师傅" × "当代直男朋友"的混合气质**——不能太冷（像 MUJI 那种无人性的极简），也不能太甜（像小红书诗人那种柔软），应该在两者之间偏硬一点的位置。
- **"可书写"是产品内核**。任何不能为"用户拿出笔来写"服务的视觉都应该被砍掉。华丽封面可以有，但内页底色、字体、笔记区位置都要让人**"想动笔"**。
- **"小红书渠道"意味着视觉要经得起手机屏幕上 3 秒的判断**。封面主标题（一个"乾"字 + 一个 ☰ 符号）**在 500×500 缩略图里就要能识别出来**。这几乎排除了任何"远看是一片糊"的复杂封面。

**最关键的一条——易经卦象本身就是现代设计语言**：

☰（乾）是三条实线。☷（坤）是三条断线。整个易经的 384 个爻 = 阴阳两种基本符号的排列组合——**这在视觉上本质就是极简几何图形**，比任何当代设计师设计的 logo 都更纯粹、更二进制、更模块化。

这一点极其重要：**学习本的视觉识别系统，最有力的候选就是"卦象本身 + 最少的辅助信息"**。

在我们调研的所有参考中，有几个特别印证了这件事：
- **原研哉**的白 — 证明"一个符号 + 大量留白 = 一个品牌"
- **杉浦康平**的曼荼罗设计 — 证明东方抽象几何可以用最严谨的网格承载
- **朱赢椿**的《虫子书》 — 证明"符号就是内容"
- **中川政七商店** — 证明品牌 logo 可以就是"中川政七"四个字 + 一个纯色块

学习本最幸运的地方是：**我们不需要发明一个符号——五千年前的古人已经画好了**。我们要做的只是**不要把它埋在红金水墨的装饰里，让那三条线/六条线自己说话**。

这就是为什么日本设计值得学习本重度参考：**日本人懂得一件事，中国人常常忘记——"这东西本身就足够漂亮，你要做的是不碍它"**。
